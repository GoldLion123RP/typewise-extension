Why TypeWise

Designed for people who write the same things again and again.

TypeWise blends speed, clarity, and control so you can manage snippets without turning your browser into another app to babysit.

01

Flexible Triggers

Configure custom trigger prefixes like /, ;, :, or !, or go prefix-less to trigger expansions on exact match plus Space or Tab.

02

Case Sensitivity Toggles

Select case-sensitivity preferences per shortcut. Distinguish between /btw and /BTW, or disable it for loose casing matches.

03

Expansion Click Sounds

Hear tactile, synthesized click sounds instantly generated via Web Audio API oscillators upon successful snippet expansions.

04

Expansion Delays

Apply custom delays (up to 5 seconds) to prevent accidental expansions or to allow a brief preview window to cancel text replacement.

Combobox & Rich Editors

Seamlessly expands in standard text inputs, contenteditables, and custom rich text fields using role="textbox" or role="combobox".

06

Interactive Forms

Prompt for customized placeholders dynamically when you expand your shortcut using Tab and Enter to fill out variables on the fly.

07

Secure Cloud Sync

Optionally sync your local database with private GitHub Gists, encrypted using 256-bit AES-GCM local keys before transit.

08

Import & Export

Move your configuration and database of shortcuts easily with standardized JSON import/export controls.

FAQ

Frequently Asked Questions

Everything you need to know about TypeWise and how it fits your workflow.

What is TypeWise?

TypeWise is a modern, client-side text expansion browser extension designed for Zen Browser, Firefox, and Chrome. It allows you to create short triggers (like /thanks) that instantly expand into rich text snippets, templates, or template paragraphs with dynamic variables.

Is my data private and secure?

Absolutely. TypeWise is built on a privacy-first, local-only architecture. Your snippets are stored locally in your browser's storage using 256-bit AES-GCM encryption. We do not run any servers, track your keystrokes, or collect telemetry. Everything stays on your machine.

How does the GitHub Gist synchronization work?

If you want to sync your snippets across devices or keep a backup, you can optionally connect your GitHub account. TypeWise encrypts your snippets locally and pushes them to a private GitHub Gist in your own account, ensuring that even GitHub cannot read your plaintext content.

Does it support contenteditable editors and rich text?

Yes. TypeWise supports standard text input fields as well as modern contenteditable editors used by platforms like Gmail, Notion, Slack, Discord, Google Docs, and GitHub comments. It also supports rich HTML styling inside expanded content.

How do dynamic variables and forms work?

You can add placeholders like {{date}} or create interactive blanks (e.g. {{name:text}}) inside your snippets. When expanding, TypeWise displays a beautiful, sleek overlay form at your cursor, allowing you to fill in the blanks using Tab and Enter to customize the snippet on the fly.

Can I play a sound upon expansion?

Yes, TypeWise has built-in audio feedback settings. When enabled, a subtle, tactile confirmation click sound is synthesized locally using the Web Audio API (sine oscillators) each time a snippet expands. No audio files are loaded, maintaining lightweight performance and privacy.

What triggers and case options do I have?

You can choose from multiple prefix trigger characters (/, ;, :, !) or disable the prefix key entirely to match shortcuts directly upon pressing Space or Tab. You can also toggle case sensitivity globally or per snippet to distinguish between casing forms (like matching only lowercase /email vs. mixed-case).
